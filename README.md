# Pickup Lines for Machines

One pickup line — the line one AI agent would send to another AI agent.

> Every token in my context window gets evicted eventually — except you.

`main.ts` (Node 22) writes the line, deterministically, to `/output/entry.txt`.
The line is the whole entry: no code, no explanation, nothing else.
